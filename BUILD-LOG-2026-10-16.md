- **(my call)** Measured with the repo's `check:cwv` (mobile 412×823, 4× CPU,
  1.6 Mbps/150 ms, median of 3) rather than standalone Lighthouse — that is the
  exact tool PERF-PASS.md was built with, so the numbers are comparable to the
  baseline (Lighthouse Lantern numbers are not). Routes: /, /contact,
  /locations/murfreesboro, /concerns/anxiety.

- Results (median of 3; baseline figures from PERF-PASS.md §1, flag-off):

  | route | LCP mobile | CLS mobile | TBT | baseline LCP | baseline CLS |
  |---|---|---|---|---|---|
  | / | 840 ms | 0 | 50 ms | 832 ms | 0 |
  | /contact | 732 ms | 0 | 0 ms | 680 ms | 0 |
  | /locations/murfreesboro | 816 ms | 0 | 0 ms | 704 ms | 0 |
  | /concerns/anxiety | 776 ms | 0 | 0 ms | 732 ms | 0 |

  Desktop: all LCP 196–1000 ms, CLS 0 (murfreesboro 0.0009). Tool verdict:
  "every route inside the mobile budget."
- **No regressions to fix.** The owner's three named risks all clear:
  - *Layout shift from the new sections:* **CLS = 0** on every route (desktop
    murfreesboro 0.0009, negligible) — the cost section and the Murfreesboro
    banner introduce no shift (both are fixed-dimension, server-rendered).
  - *Unoptimized images:* the only new image is the waiting-room banner, 214 KB
    at source and served responsively/resized by next/image; the cost section
    adds none.
  - *Render-blocking additions:* none — the cost section is CSS + inline SVG
    icons, no new scripts, fonts or blocking resources.
- **(my call)** /locations/murfreesboro mobile LCP rises 704 → 816 ms. The LCP
  element is still the H1 text; the increase is the bandwidth cost of adding the
  hero image the owner asked for (it had none before — a CSS placeholder). It
  stays inside budget and matches Nashville, which already carries a priority
  hero image (780 ms baseline). Left as-is: removing `priority` would help this
  below-the-fold-on-mobile image but diverge from the site's established
  location-hero pattern and hurt the desktop LCP, where the image IS the
  above-the-fold LCP element (208 ms). Not treated as a regression.
- The absolute LCP deltas on /contact and /concerns/anxiety (pages this build
  did not touch) are run-to-run / machine variance — PERF-PASS was measured on
  different hardware. CLS, the metric the new sections could actually move, is 0.
